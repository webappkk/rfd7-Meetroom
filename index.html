ตั้งค่า LINE OA (Messaging API) ยังไม่ตั้งค่า
วิธีหา LINE Group ID:
1. เพิ่ม LINE Bot เป็นสมาชิกในกลุ่มที่ต้องการ
2. ไปที่ LINE Developers Console → Messaging API → Webhook URL
3. ตั้ง Webhook URL เป็น URL ของ Apps Script นี้
4. ส่งข้อความใดก็ได้ในกลุ่ม → ดู Webhook log → หา source.groupId (ขึ้นต้น C...)
⚠️ หรือใช้เครื่องมือ webhook.site รับ event แล้วคัดลอก groupId
วิธีตั้งค่า LINE OA Channel:
1. ไปที่ LINE Developers Console
2. เลือก Channel → แท็บ Messaging API
3. เลื่อนหา Channel access token → คลิก Issue
4. นำ Token มาวางในช่องด้านบน และตั้ง Auto-reply = Disabled
